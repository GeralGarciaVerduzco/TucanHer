# Colaborar en CanastaScan

- Crea una tarea y asígnale un responsable antes de programar.
- Nombra ramas como `feat/modulo`, `fix/problema`, `docs/guia`.
- Escribe Pull Requests pequeños y agrega capturas móvil y escritorio.
- Comprueba rutas, navegación, estados vacíos y accesibilidad básica.
- No subas secretos ni datos personales a repositorio, tickets o issues.
- No uses marcas de supermercados reales para afirmar precios no verificados.
- Los responsables de diseño revisan la consistencia en color, espaciado y botones.

## Checklist PR

- [ ] `npm run typecheck`
- [ ] `npm run lint`
- [ ] `npm run build`
- [ ] Demo en vista de 390px
- [ ] Prueba manual del flujo relevante
- [ ] Capturas y descripción de cambios
